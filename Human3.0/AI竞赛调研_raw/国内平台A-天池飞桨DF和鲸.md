# 国内AI竞赛平台调研（AI应用开发 / 大模型应用 / LLM Agent / AI Hackathon）

## 抓取日期与来源说明
- **抓取日期**：2026-10-11（周日，UTC+8）
- **调研基准**：仅收录报名截止日期落在 2026-10-11 至 2026-12-31 之间、且报名通道仍开放（或即将开放）的赛事；已截止赛事不收录。
- **调研平台**：阿里云天池、百度飞桨 AI Studio、DataFountain、和鲸社区。
- **方法**：通过 general_search 实时检索 + web_fetch 直接访问各平台官方列表页/详情页核实。天池与和鲸竞赛列表页为 JS 动态渲染，web_fetch 仅拿到骨架，故改用魔搭（ModelScope，天池合作主办方）赛事页、天池技术圈论坛规则帖、第三方赛事聚合站交叉核实；AI Studio 竞赛列表页返回 ACCESS DENIED，改用公开报道核实其赛事周期。
- **重要提示**：DataFountain PC 端列表页（www.datafountain.cn/competitions）显示的"火热报名中"标签为 SSR 缓存，与 wap 端实时状态（wap.datafountain.cn/competitions）不一致；本调研以 wap 端实时状态为准。

## 二、百度飞桨 AI Studio（aistudio.baidu.com）

### 结论：该平台无符合条件赛事

- 直接访问 `https://aistudio.baidu.com/competition` 返回 **ERROR: ACCESS DENIED**，无法在抓取时实时核实列表。
- 通过公开信息核实：**飞桨黑客松第十期（文心合作伙伴赛道）**主周期为 2026-03-12 至 **2026-09-29**（hackertrip.space 赛事日历），设开源贡献、PaddleOCR+ERNIE 等 7 条赛道，报名通过 GitHub Issue #78485 进行；截至 2026-10-11 主周期已结束。
- 检索 2026 年 10 月在报名的"飞桨/AI Studio 大模型应用/Agent 比赛"，未发现落在 2026-10-11 至 2026-12-31 窗口内的正式赛事（仅见历史 Foundathon/Hackathon 留存页与 2024–2025 年旧闻）。
- **备注**：百度系大模型智能体相关赛事需另行关注"文心智能体平台（agents.baidu.com/activity/center）"与"百度飞桨黑客马拉松新一期"官宣，本次未在 AI Studio 主站发现可报名条目。
