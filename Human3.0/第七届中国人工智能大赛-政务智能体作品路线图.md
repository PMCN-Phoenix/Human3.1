## 〇、一句话产品定义

**政务公文起草智能体**：输入零散材料（会议记录/上级要求/已有素材）→ 自动生成符合 GB/T 9704 格式的规范公文初稿（请示/通知/纪要）→ 格式校验 + 合规自查 → 一键导出 docx。全程**私有化部署，数据不出域**——这是与通用大模型工具的最大差异化。

```
│  ①文种识别 → ②RAG检索素材 → ③起草初稿              │

└───────────────┬─────────────────────────────────┘
                │
┌───────────────▼─────────────┐  ┌────────────────┐
│ RAG 向量库（本地）            │  │ 规则引擎         │
│ · 本单位公文模板库            │  │ · GB/T9704格式校验│
│ · 政策文件/办文规范           │  │ · 敏感词/规范表述  │
│ · 历史请示/通知样例           │  │ · 涉密信息提醒    │
└─────────────────────────────┘  └────────────────┘
```

**技术选型**（你有牌，直接用）：
- 大模型：本地部署或 API（**论文稿里写清"数据不出域"方案**——这是成效20分的关键）
- RAG：本地向量库（如 Chroma/Milvus 或轻量方案）+ Embedding
- Agent：工作流编排（LangGraph/自写状态机，展示你能讲清楚）
- 导出：python-docx 生成标准公文格式
- 前端：简洁演示页（Streamlit/FastAPI+HTML 均可）

**创新点包装（论文稿素材）**：
1. **格式即规则**：GB/T 9704 硬校验引擎（标题/主送/正文/落款/日期全要素校验）——通用大模型不会这个
2. **合规自查前置**：敏感表述、涉密提醒进生成链路，不是事后过滤
3. **私有化=合规**：数据不出域架构图，正面回应"政务信息安全合规底线"
